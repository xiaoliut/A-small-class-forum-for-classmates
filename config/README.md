# 📁 配置文件夹 —— 所有「可以改的东西」都放这里

这个文件夹的作用：把**你日常会修改的内容**和**程序代码**分开。
正常使用论坛时，你只需要动这个文件夹（或后台的「站点设置」页），**不需要看 `src/` 里的任何代码**。

> 改完怎么生效？两种方式任选：
> 1. 登录管理员账号 → 后台「站点设置」→ 点 **🔄 重新加载配置**（立即生效，不用重启）
> 2. 或者重启服务：`npm run stop && npm run serve`
>
> 后台「站点设置」页保存时，会**同时写回 `config/site.jsonc`**，所以两种改法不会互相覆盖。

---

## 一、这个文件夹里的文件

| 文件 | 管什么 | 常见修改场景 |
| --- | --- | --- |
| `site.jsonc` | 站点名称、副标题、介绍、管理员联系方式、**页脚版权**、**ICP/公安备案号**、自定义底部文字、页脚链接、功能开关 | 换个班级名、填备案号、关闭注册、改成先审后发 |
| `sections.jsonc` | 论坛分区（板块）：名称、图标、说明、是否仅管理员可发 | 加一个「互助求助」板块、把「公告通知」改名 |
| `moderation.jsonc` | AI 审核规则：敏感词、权重、风险分阈值、分区建议词 | 加了新的广告话术、想去掉某个误判词 |
| `user/` | 预留给你放自己的东西（备份、草稿等），程序不会读它 | 存放配置备份 |

**格式说明**：`.jsonc` 就是带注释的 JSON，支持 `//` 行注释、`/* */` 块注释和尾随逗号。
删掉某个字段 = 该字段恢复默认值；**把整个文件删掉，论坛照样能正常启动**（用内置默认值）。

## 二、不在这个文件夹、但也可以改的东西

| 位置 | 管什么 | 说明 |
| --- | --- | --- |
| `.env` | 端口、监听地址、会话密钥、访问日志、AI 接口地址与密钥 | **部署相关**，从 `.env.example` 复制而来。改完需要重启服务 |
| 后台「帖子审核 / 评论管理 / 用户管理」 | 具体内容与账号的操作 | 删帖、置顶、警告、禁言、封号——这些是**运行时数据**，存在数据库里，不在配置文件 |
| `data/forum.db` | 全部业务数据（用户、帖子、评论、举报、日志） | 备份就备份这个文件；不要手动编辑 |
| `public/css/style.css` | 颜色、圆角、间距等视觉样式 | 想换主题色改开头的 `:root` 变量即可 |

## 三、优先级（后写的覆盖先写的）

```
1. 程序内置默认值（最底层）
2. config/site.jsonc          ← 配置文件
3. 后台「站点设置」保存的值    ← 数据库，优先级最高
```

所以：**后台改过的字段会盖住配置文件**。如果发现改了 `site.jsonc` 没反应，
去后台「站点设置」点一下 **恢复为配置文件默认值**（清掉数据库覆盖），再点 **重新加载配置**。

## 四、几个常见改法示例

### 1. 填写 ICP 备案号 + 自定义底部文字（最常用）

```jsonc
{
  "footer": {
    "copyright": "© 2024-2026 XX中学高一(3)班",
    "icp": "京ICP备2024000000号-1",
    "police": "京公网安备 11010502000000号",
    "customText": "本站仅用于班级内部学习交流，请勿转载到公开平台",
    "extraLines": ["内容版权归原作者所有", "有问题请联系超级管理员"],
    "links": [
      { "label": "论坛规范", "href": "/rules" },
      { "label": "学校官网", "href": "https://example.com", "icon": "🏫" }
    ]
  }
}
```

### 2. 改成「所有帖子先审后发」

```jsonc
{
  "features": {
    "aiModeration": true,
    "aiAutoApprove": false   // ← 取消自动通过
  }
}
```

### 3. 加一个论坛分区

`sections.jsonc`：

```jsonc
{
  "sections": [
    { "key": "general", "name": "综合讨论", "icon": "💬", "desc": "什么都可以聊两句" },
    { "key": "help",    "name": "互助求助", "icon": "🆘", "desc": "作业求助、失物招领" }
  ]
}
```

> `key` 建议用英文短词，改动后**老帖子仍留在原分区**（数据库里记的是旧 key）。

### 4. 加一个自己的违禁词类别

`moderation.jsonc`：

```jsonc
{
  "categories": {
    "校外培训": { "weight": 30, "words": ["一对一辅导", "提分班", "名师押题"] }
  }
}
```

> 正则里的反斜杠要写两次：`\b` 写成 `\\b`、`\S` 写成 `\\S`。

## 五、改坏了怎么办

- **论坛起不来 / 页面报错**：把改过的 `.jsonc` 文件重命名或删掉，重启即可（程序会用内置默认值）。
- **只想恢复出厂设置**：后台「站点设置」→ 恢复为配置文件默认值；或删掉 `data/forum.db` 后 `npm run reset-db`（注意：会清空所有帖子与账号）。
- **改完没反应**：先点后台「🔄 重新加载配置」；还是不行就看后台页面右上角列的「可修改的文件」，确认文件是「可写」状态。
